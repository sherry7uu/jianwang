# 鉴往

**拿不准的时候，借前人的经历，想清楚自己的下一步。**

如果你最近正卡在一个选择上，可以来跟鉴往聊聊。

换不换工作、要不要创业、还要不要继续合作，或者一段关系里该付出到什么程度。这些事，光听别人说一句“你应该怎样”，往往还是拿不定主意。

鉴往想做的，就是像一个愿意认真听你说话的朋友，陪你把事情捋清楚。先看看你在乎什么、已经做成过什么、手里有多少时间和余地，再从历史和社会经验里找参照：别人遇到类似处境时怎么选，后来怎么样，付出了哪些当时没想到的代价。最后，再回到你的情况，看看接下来哪一步更合适。

## 哪些时候，可以来聊聊

| 你正在纠结的事 | 比如这些场景 | 鉴往可以帮你理清什么 |
| --- | --- | --- |
| 工作要不要换 | 老板不重视自己；拿到晋升机会，但责任和资源没说清；想辞职又怕断了收入 | 比较留下、沟通、换岗位、准备离开的得失，看看你现在有哪些条件，还缺什么 |
| 创业或项目要不要做 | 有个想法想全职投入；还没有付费客户；预算和人手不够，却要答应一个大项目 | 把经验、钱、时间和任务放在一起看，找出能先试的一小步，以及失败后能不能承受 |
| 合作和人际怎么处理 | 合伙人说得好听却迟迟不兑现；朋友之间总是自己退让；团队里争功、站队 | 分清共同目标、实际付出、各自的选择和边界，比较继续谈、调整合作或退出 |
| 感情和家庭里怎么选 | 不知道该继续投入、把话说开，还是拉开距离；一边顾家，一边舍不得自己的机会 | 把你的期待、对方实际做过的事、双方承担的代价说清楚，再比较几个选项。现有资料在感情上的借鉴有限，主要讨论信任、承诺和边界 |
| 大环境变差，生活怎么安排 | 行业在裁员，想转行；收入不稳，又背着房贷；担心经济低迷拖很久 | 参考日本泡沫、就业冰河期和美国金融危机的经历，检查收入、负担和工作机会可能怎样一起变化，再讨论你的准备 |
| 想看看“以后会怎样” | 对未来没底，想知道一件事走下去会有什么结果 | 先把问题缩小：你正在选什么、看多长时间，再分别想一想顺利、受阻和恶化时怎么应对，以及出现什么信号就该调整 |

这些问题都可以拿来讨论。遇到缺信息或找不到合适案例的地方，鉴往会把缺口说出来，先陪你找值得核实的事。

## 它会怎么陪你想

1. **先听你的情况。** 你想要什么、最不愿意失去什么、已经试过什么。说不清也没关系，可以边聊边捋。
2. **找能用得上的参照。** 从指定资料里找处境相近的案例，说明别人当时有哪些选择、为什么那么选、后来发生了什么，并标明出处。
3. **把几条路摊开看。** 每条路能得到什么、可能失去什么，会不会越走越难回头。那些藏在后面的时间、精力、信任和机会成本，也一起算进去。
4. **落到你做得到的一步。** 结合你的经验、收入、负担和精力，看看可以先做什么，过一段时间检查什么，什么情况下需要换个办法。

同一件事，放在不同人身上，建议可能不同。范蠡离开越国时，有经验、财富和随行的人；一个手里只有三个月生活费、还没找到客户的人，需要考虑的条件就很不一样。鉴往会把这些差别摆出来，帮你判断哪些经验能借，哪些条件需要先补上。

## 现在已经包含哪些资料

| 资料 | 目前包含什么 |
| --- | --- |
| 《史记》 | 130卷的固定版本来源，可下载到本机检索；适合从人物经历里讨论去留、用人、承诺和选择 |
| 《资治通鉴》 | 294卷的固定版本来源，可下载到本机检索；适合从事件变化里讨论合作、冲突、组织和利益关系 |
| 核对过的古籍案例 | 11个案例、23段原文，包括范蠡、张良、蔺相如、李牧、王翦、萧何、韩信、李斯、智伯和李克等人的选择 |
| 现代社会案例 | 3个案例：日本泡沫与信用变化、日本就业冰河期、美国2007—2009年衰退。保存机构研究的简短摘要和来源链接 |

仓库自带这14个案例，可以先读案例和原文选段。两部古籍共424卷的全文，安装后可按清单下载；现有案例没有穷尽两部书的所有选择。

《甄嬛传》和其他人情书目前还没加入。后续会按来源逐步扩充。

历史人物有他们的时代、地位和条件，日本与美国也有各自的制度。鉴往会说明这些差异；案例是帮助你检查想法的参照，现实建议还需要结合当下事实。未来推演会讲条件和信号，不给你保证会发生的结局。

## 你可以直接这样聊

```text
我想辞职创业，但只有三个月生活费，还没有付费客户。
帮我先看看我现在的条件，再比较直接辞职、边工作边试、先换份工作这几条路。
找些能核对出处的历史案例，也说说它们跟我的情况哪里不一样。
```

```text
合作方总说以后会补偿我，但最近几次都是我先投入。
我不知道该继续相信、把条件说清楚，还是退出。
先帮我捋一捋事实和我的底线，再借历史案例看看几种选择的代价。
```

也可以先读[辞职创业的完整示例](examples/career.md)，看看最后会聊到什么程度。示例是虚构的，没有使用真实用户的私人经历。

## 怎么用

鉴往是一个装在支持技能的 AI 助手里使用的开源工具。安装后，像平时聊天一样描述你的问题就行；理解问题、讨论选择和组织回答由 AI 助手完成，本项目负责提供方法、资料和检索工具。

<details>
<summary>安装到 Codex</summary>

需要 Python 3.10 或以上，没有额外 Python 依赖。检索脚本无需 API Key；AI 助手本身按你使用的服务运行。

将仓库放进技能目录，目录已存在时先检查，避免覆盖：

```bash
git clone https://github.com/sherry7uu/jianwang.git ~/.codex/skills/history-decision
```

打开新的聊天，直接描述问题，或明确调用：

```text
使用 $history-decision，陪我把这个选择想清楚。
```

项目中文名是“鉴往”，技能调用名保留为 `history-decision`。其他支持 `SKILL.md` 的宿主也可按自己的技能目录安装，需要能读取文件、运行 Python。

</details>

<details>
<summary>下载原文、检索案例与检查资料</summary>

在仓库目录运行：

```bash
python3 scripts/history.py search '辞职 创业 资源 退出' --modules classics
python3 scripts/history.py read fanli-exit
python3 scripts/history.py search '日本就业冰河期，失业后转行' --modules modern
```

下载和检索两书全文：

```bash
python3 scripts/bootstrap.py
python3 scripts/history.py text 韓信 蒯通 --books shiji
python3 scripts/history.py verify --full
```

下载仅访问清单指定的维基文库，固定每卷修订号与文本哈希，支持中断续传。全文保存在 `.cache/`，不提交到公共仓库；版本变化造成提取哈希不符时会报告，需维护者核对。

只下载部分卷可用 `--books shiji --volumes 41 55 81 92`。只查《史记》案例可加 `--books shiji --modules classics`。`verify` 可以核对随包选段与清单，`verify --full` 还要求424卷缓存齐全，并检查原文位置。

脚本按关键词初步分流，助手结合语义复核。案例召回使用中文二元字词 BM25 和人工标签；正文按原字检索，必要时尝试简繁与异体。检索分数只用于寻找候选，不代表建议可信度或现实成功概率。

古籍使用源站转录版本，未独立进行学术校勘。整理时去除导航、参考注与校勘区，仍可能保留编者标题和古代评论；逐字检查说明引句来自固定快照，不证明史书记载本身没有争议。

检查命令：

```bash
python3 -m unittest discover -s tests -v
python3 scripts/history.py verify
```

检查覆盖来源范围、引用与缓存是否被改动、固定版本下载、同一事件去重、资料过滤和无结果处理，不等于验证了 AI 给出的每条人生建议。

</details>
