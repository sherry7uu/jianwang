# 鉴往 · 人生抉择教练

**从历史找参照，根据你的能力与资源推演选择。**

这是一个面向 AI 助手的结构化技能，由 [sherry7uu](https://github.com/sherry7uu) 发起。它从《史记》《资治通鉴》和已登记的现代社会案例中检索证据，拆解当时的选项、判断、结果与隐性代价，再落到使用者当前做得到的行动。

一个典型问题：

> 我只有三个月生活费，老板不重视我，也还没验证创业方向。该裸辞、继续沟通，还是先做准备？请结合历史案例推演。

它会先确认你的实际经历、资源和底线，再比较退出、沟通、补条件等选项。范蠡的商业能力、财富与团队会被当成案例中的特殊条件；不会因为他后来成功，就把普通人的裸辞也判为好选择。

## 能产出什么

- 处境与能力画像：已知事实、已展示的能力、资源余量、关键未知。
- 结构相似的案例：当时可选什么、为什么选、实际结果与隐性代价。
- 原文证据：书名、卷次/篇名、原句、固定版本链接；推断与记载分别标明。
- 现实选项比较：条件、代价、可逆性，以及什么信息会改变排序。
- 人生教练式建议：当前优先动作、能力建设方向、观察信号与调整条件。

“预测未来”会转为条件情景分析。输出不包含命定结论、历史相似度换算的成功率或未经证实的人格评分。

## 当前资料

| 模块 | 已有内容 | 如何使用 |
| --- | --- | --- |
| 古籍核心 | 《史记》130卷、《资治通鉴》294卷的维基文库版本清单；共424卷 | 下载后本地全文检索，每卷修订号与文本哈希固定 |
| 古籍种子案例 | 11个案例，23段经逐字核对的原文 | 无网络、无全文缓存也能读取；可继续检索全书扩充 |
| 现代社会 | 日本泡沫信用机制、日本就业冰河期、美国2007–2009年衰退，共3张案例卡 | 3项机构资料的原创简短摘要与来源链接 |
| 后续扩展 | 其他社会、人情书、虚构作品 | 尚未接入；《甄嬛传》不在当前有效资料范围 |

案例索引不等于穷尽全书的所有抉择。全文使用源站转录版本，未进行独立学术校勘；下载过程会去除导航、参考注与校勘区，保留原字、部分编者标题和古代评论。逐字校验证明引句来自固定快照，不证明叙事本身无争议。

## 使用

需要 Python 3.10 或以上，无额外 Python 依赖，无需 API Key。技能的理解、推演与写作由支持技能的 AI 助手完成；命令行提供确定性的路由提示、检索与证据校验。

### 安装到 Codex

将本仓库克隆到技能目录（目录已存在时不要覆盖）：

```bash
git clone https://github.com/sherry7uu/history-decision-skill.git ~/.codex/skills/history-decision
```

在新的聊天中直接描述选择，或明确调用：

```text
使用 $history-decision：我正在考虑辞职创业，请先了解我的能力和资源，再从指定案例库帮我推演。
```

其他支持 `SKILL.md` 的宿主可将仓库放进自己的技能目录；需由宿主提供文件读取和 Python 执行能力。

### 先体验选段检索

在仓库目录运行：

```bash
python3 scripts/history.py route '感情中我该继续付出，还是设立边界？'
python3 scripts/history.py search '辞职 创业 资源 退出' --modules classics
python3 scripts/history.py read fanli-exit
python3 scripts/history.py search '日本就业冰河期，失业后转行' --modules modern
```

### 下载与检索两书全文

```bash
python3 scripts/bootstrap.py
python3 scripts/history.py text 韓信 蒯通 --books shiji
python3 scripts/history.py verify --full
```

下载仅访问维基文库，按已登记版本串行获取，可中断续传；全文保存在 `.cache/`，不提交到仓库。源站限流或不可用时会有限重试并报告具体卷次。固定修订版的模板若改变导致提取文本哈希不符，会停止接纳该卷，需维护者检查，不能静默换版本。

只下载部分卷可用 `--books shiji --volumes 41 55 81 92`。仅使用《史记》时，案例查询加 `--books shiji --modules classics`。`verify` 可以在没有全文缓存时核对随包选段及清单；`verify --full` 还要求424卷全部存在并核对原文偏移。

## 自动选择资料的方式

事业与退出问题优先《史记》；合作、冲突和组织问题优先《资治通鉴》；涉及泡沫、就业和负债时允许加入现代模块。感情问题只借古籍讨论信任、承诺与边界，并承认亲密关系与君臣关系的差异。

脚本用关键词进行初步分流，案例召回用中文二元字词 BM25 与人工场景标签。助手结合语义复核、识别交叉场景、比较实际结构；模糊时询问，不承诺全自动准确分类。正文按原字精确检索，可尝试简繁与异体词。用户指定资料范围时优先遵守。

更完整的工作方式见 [SKILL.md](SKILL.md)、[能力适配方法](references/coaching.md) 与 [资料扩展约定](references/extensions.md)。[辞职创业示例](examples/career.md) 展示最终交付形式。

## 验证与贡献

```bash
python3 -m unittest discover -s tests -v
python3 scripts/history.py verify
```

检查覆盖来源范围、同事件去重、引文及缓存篡改、固定版本下载、现代与古籍过滤，以及无结果时的处理。它们验证检索与证据约束，不等同于验证 AI 给出的每一条人生建议。新增案例请遵循 [贡献说明](CONTRIBUTING.md)。
