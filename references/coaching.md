# 能力、处境与人生教练方法

目标是找出此人在当前约束下能执行、且值得尝试的做法。历史人物的能力不是用户的最低门槛。

## 最小画像

按需要问，不把每次使用变成问卷。只在用户已提供相关信息时引用其过往，不主动读其他私人记录。

| 维度 | 可观察信息 | 尚无证据时 |
| --- | --- | --- |
| 技能与判断 | 相似任务的成果、独立完成部分、复盘及预测命中情况 | 区分自评、第三方反馈和实际结果，先给验证任务 |
| 行动稳定性 | 近期能持续做的行动、碰到挫折的反应 | 询问近期实例，不贴“软弱/心性低”标签 |
| 资源余量 | 可用时间、必要支出、收入稳定性、债务、照护责任 | 给不同资源条件的分支，不默认“至少有六个月积蓄” |
| 关系与权力 | 谁能拒绝、谁有替代方案、承诺如何兑现 | 不凭单方叙述断言另一方动机 |
| 精力与支持 | 当前负荷、可信帮助、恢复条件 | 缩小动作复杂度，不作心理诊断 |
| 目标与底线 | 主要目标、不可牺牲事项、失败成本 | 让用户选择权重；不给凭空总分 |

## 建议怎样随能力变化

“范蠡离开后还能经商”不等于“任何人裸辞都能致富”。分析离开时的财富、谋生能力和团队，再翻译为：保留收入、验证需求、积累可展示成果、谈妥交接、确认替代去处等可逆步骤。

“蔺相如愿意退让”的叙事包含其既有声望和共同保卫赵国的目标。用户在关系中如果缺少对等尊重，不能据此劝其无限忍让。区分一次退让、反复吞损失与清晰边界下的合作。

“王翦坚持六十万兵”有其军事成绩与不可轻易替代的地位。普通员工可以先量化任务与资源缺口、做小规模验证、明确职责，不必模仿君臣间的政治信号。

给两层建议：

- 当前可执行的动作：在已知资源与精力内推进一小步。
- 扩大选择空间的建设：补技能、证据、替代机会或支持网络，说明哪些新增条件会让更进取的方案变得可行。

用户无法承受的高风险方案不要排在首位。用户有能力但受结构限制时，不能把宏观阻力归咎于个人不努力；能力强也不能取消现金流、健康或照护约束。

## 校准与复盘

标明建议依赖的假设、最脆弱环节和反证。用下一次谈话/试做结果更新建议。用户主动要求长期记录时再创建去标识的个人决策档案，与公共历史库分开，公开提交永远排除个人档案。

不通过故事的数量制造把握感；不存在历史频率到个人成功率的直接映射。“更适合当前目标”必须说明目标和条件，不能声称已客观测定用户能力或找到了必胜方案。
